## Description

FIFTY-FIVE is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. It features a comprehensive checklist with progress saved in your browser, export/import functionality, filters by trophy kind and grade, a spoiler mode for the 28 hidden trophies, an eight-stage roadmap to the platinum, the one reported missable trophy (Positive Mental Attitude, Chapter 1 meditation) flagged up front, and a detailed guide for every trophy with facts sourced from PowerPyx, GTABase, Exophase, and PSNProfiles.

## Run it

To run the application locally, you can use:

```bash
node serve.ts
```

Then, open `http://localhost:8080` in your web browser. Alternatively, you can serve the `app/` directory using any static web server.

## Hand it in

To generate the final output dossier:

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
